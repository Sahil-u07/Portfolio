# Sahil Lenka Portfolio (Final Version)

A premium single-page portfolio site.

## Run locally

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

## Add your exact images

Use these file names in `assets/`:

- `profile-main.jpg` (front portrait)
- `profile-back.jpg` (sunset/back shot)
- `profile-classic.jpg` (yellow kurta portrait)

The HTML is already wired to these names, so your photos will show automatically.
